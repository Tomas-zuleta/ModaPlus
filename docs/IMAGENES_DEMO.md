# Imágenes temporales para probar el flujo de ModaPlus

Se incorporaron fotografías de demostración mediante URLs de Unsplash para los 13 productos del catálogo local y las tres colecciones destacadas.

Estas fotografías **no corresponden necesariamente a los productos reales** de ModaPlus. Son solo recursos ilustrativos para navegar desde Explorar hasta el catálogo, el detalle de producto y el carrito.

- La app necesita conexión a Internet para cargar las imágenes.
- Si una imagen falla, se muestra un fondo degradado y un icono de categoría.
- Las URLs están centralizadas en `lib/data/demo_images.dart` para facilitar su sustitución.
- Antes de publicar la aplicación, reemplazar estas fotos por imágenes oficiales con derechos de uso adecuados, preferiblemente procedentes del catálogo de Supabase Storage.
- Las compras y pedidos siguen siendo de demostración, sin persistencia de producción.
- No se ha modificado el repositorio web.
