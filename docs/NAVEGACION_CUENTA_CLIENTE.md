# Navegación de cliente y cuenta

- Menú inferior: Explorar, Catálogo, Favoritos, Perfil.
- Menú lateral: Resumen de mi cuenta, Mis compras, Mis planes separe, Mis datos, Configuración, Cerrar sesión.
- Las pantallas del menú lateral se abren como rutas independientes, sin duplicar la navegación inferior.
- Mis compras reutiliza el filtro por correo de la sesión de demostración y muestra detalle de pedidos.
- Los planes separe del conjunto de datos local pertenecen a clientes ficticios distintos: no se muestran como si fueran del usuario conectado.
- Favoritos y planes separe están preparados visualmente, pero necesitan almacenamiento y consulta por usuario autenticado.
- La edición de perfil actual se guarda solo en memoria y no actualiza Supabase.
- No se ha modificado el repositorio web.
